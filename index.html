📌 [실습 7] 크롬 확장 프로그램 변환 전 사전 확인 질문 (Inquiry)

在修改代码前，根据指导要求为您准备的3个核心技术确认问题：

1. 데이터 저장 방식 (Storage Mechanism):
추천 옵션 A: chrome.storage.local 비동기 저장 방식 (크롬 확장 프로그램 공식 표준 권장, 확장 팝업을 닫고 다시 열거나 브라우저를 재시작해도 가장 안정적으로 유지됨).
옵션 B: 기존 localStorage 동기 저장 방식 유지 (기존 웹앱 코드를 100% 그대로 유지할 수 있으며 별도의 manifest 권한이 필요 없음).
2. 필요한 권한 (Permissions):
추천: chrome.storage.local을 쓸 경우 "permissions": ["storage"] 최소 권한 1개만 요청합니다. localStorage를 그대로 쓸 경우 "permissions": [](0개 권한)로도 완벽하게 동작합니다. 방문 웹페이지 읽기나 불필요한 외부 권한은 일절 배제합니다.
3. 기존 메뉴 데이터 처리 방법 (Data Migration):
추천: 확장 프로그램 첫 설치 시 한국/중국 대표 점심 메뉴 6종(김치찌개, 비빔밥, 돈까스, 마라탕, 제육볶음, 초밥)을 기본 프리셋으로 자동 세팅하고, 사용자가 추가/삭제한 메뉴가 브라우저에 영구 보존되도록 구성합니다.
